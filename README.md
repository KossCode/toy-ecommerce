# Trio Mio CRM

Адмінка CRM на React (Vite) з файловим моком API (Express + JSON у `data/`).

## Запуск

```bash
npm install
npm run dev
```

- UI: http://localhost:5173  
- API: http://localhost:3001  

Дані: `data/products.json`, `data/orders.json`, `data/integrations.json`, `data/meta.json`.

Дизайн і рішення — у `docs/`.
