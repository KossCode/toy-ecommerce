# 08. Бренди

Волна 2, экран 8.

- Устройство: desktop 1440
- Оболочка, таблица, чипы, боковая панель — из фундамента
- Данные — [`sample-data.md`](sample-data.md), «Бренды»

## Зачем этот экран

Бренд — частая причина, почему товар не уходит на площадку. Epicentr принимает только бренды из своего справочника, Prom молча отбрасывает бренд, которого нет в его базе, Rozetka без бренда товар не берёт. Экран показывает, какие бренды где сопоставлены, и что делать, если бренда у площадки нет.

Заголовок: H1 `Бренди`, мета `20 брендів`. Primary `Додати бренд`.

## Не делать

- Логотипы брендов.
- Страницу бренда для витрины: она появится в «Контенті».

## Приёмка

- Видно, какие бренды блокируют площадку и сколько товаров это задевает.
- Понятно, что сделать с брендом, которого нет у площадки.
