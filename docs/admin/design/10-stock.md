# 10. Наявність

Волна 1, экран 10. Актуальные остатки по артикулам — не журнал приход/расход.

- Устройство: desktop 1440
- Оболочка, фильтры, таблица, боковая панель — из фундамента
- Данные — [`sample-data.md`](sample-data.md)

## Зачем этот экран

Выставить текущее `всього` по артикулу. Система считает резерв и доступно; доступный остаток уходит на все включённые площадки.

## Макет A: список остатков

Текущий пункт `Наявність`.

Заголовок: H1 `Наявність`, мета `248 товарів · 12 закінчуються · 9 немає`. Primary `Змінити залишок`.

Вкладки: `Усі` (текущая) · `Закінчуються 12` · `Немає в наявності 9` · `З резервом 5`.

Строка фильтров: поиск `Назва або артикул`, селекты `Категорія`, `Наявність`, ссылка `Скинути`.

Подпись над таблицей: `Доступно = всього − резерв. На майданчики йде доступно. Нове замовлення резервує залишок одразу.`

Таблица:

| Колонка | Пример |
| --- | --- |
| Фото | 40px |
| Товар | название, под ним артикул |
| Всього | `16` вправо |
| Резерв | `3`, ссылка на заказы если > 0 |
| Доступно | `13` |
| Наявність | чип |
| Статус CRM | `Активний` / `Чернетка` |
| Синк | `Так` / `Ні` (черновик или все каналы выкл.) |

Строки из образца остатков. У TM-10018 резерв 3 со ссылкой `3 замовлення`.

## Макет B: изменить остаток

Справа панель `Змінити залишок`:

- `Товар` — поиск, выбран TM-10018
- Строка: `Всього 16 · резерв 3 · доступно 13`
- `Нове значення «всього»` `21` шт.
- Итог: `Буде доступно: 18`
- Подпись: `Новий доступний залишок одразу піде на Rozetka, Epicentr і Prom (де товар увімкнено).`
- Primary `Зберегти`, secondary `Скасувати`

Без сегментов «Прихід / Списання / Інвентаризація» — только абсолютное значение.

## Не делать

- Журнал движений как основной экран.
- Склад с ячейками и закупочными ценами.

## Приёмка

- За секунду видно всього / резерв / доступно.
- Перед сохранением видно, каким станет доступно.
- Понятно, что уйдёт на площадки.
