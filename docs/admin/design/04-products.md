# 04. Товари: список

Волна 1, экран 4.

- Устройство: desktop 1440
- Оболочка, фильтры, таблица, чипы наличия и площадок — из фундамента
- Данные — [`sample-data.md`](sample-data.md): «Товары: остатки», «Цены по площадкам», «Товары на площадках»

## Зачем этот экран

Каталог как рабочая таблица. Главный вопрос, на который отвечает экран: какие товары продаются, а какие застряли и почему. Отсюда правят остатки и цены пачкой и находят товары, которые не готовы к площадке.

## Макет

Текущий пункт `Товари`.

Заголовок: H1 `Товари`, мета `248 товарів`. Primary `Додати товар`, secondary `Імпорт`, secondary `Експорт`.

Быстрые вкладки: `Усі 248` · `Не готові до майданчиків 42` · `Закінчуються 12` · `Немає в наявності 9` · `Вимкнені 4`. Текущая — `Усі`.

Строка фильтров: поиск `Назва, артикул або штрихкод`, селекты `Категорія`, `Бренд`, `Наявність`, `Майданчик`, ссылка `Скинути`.

Таблица:

| Колонка | Пример |
| --- | --- |
| ☐ | чекбокс |
| Фото | миниатюра 40px |
| Товар | `Конструктор LEGO City «Пожежна частина»`, под ним `TM-10018 · LEGO` |
| Категорія | `Конструктори` |
| Ціна | `1 890 грн`, под ней зачёркнутая `2 290 грн` |
| Доступно | `13 шт.`, под ним вторичным `резерв 3` |
| Наявність | чип |
| Rozetka | чип состояния |
| Epicentr | чип состояния |
| Prom | чип состояния |

Восемь товаров из образца. Цена в таблице — базовая. Цены площадок — в карточке товара.

Чипы площадок — короткие: `Активний`, `Немає в наявності`, `Під замовлення`, `На модерації`, `Не готовий`, `Вимкнено`, `Помилка`. Наведение на чип показывает причину тултипом. На макете показать один открытый тултип у TM-10042 → Epicentr: `Не заповнено: Матеріал наповнювача, Висота, см`.

У TM-10077 в колонке «Товар» вторая строка — `TM-10077 · Не вказано бренд` цветом warning.

Выбраны TM-10155 и TM-10204. Полоса массовых действий: `Вибрано 2` · `Змінити ціну` · `Змінити кількість` · `Увімкнути на майданчику` · `Вимкнути на майданчику`.

Пагинация `1–50 з 248`.

## Не делать

- Плитку карточек как на витрине.
- Цены всех трёх площадок в таблице: строка станет нечитаемой.
- Редактирование прямо в ячейке на макете. Возможно позже для количества.

## Приёмка

- По строке видно, где товар продаётся, а где нет.
- Причина «не готовий» доступна без перехода в карточку.
- Массовые действия понятны.
