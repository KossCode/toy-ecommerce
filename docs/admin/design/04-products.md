# 04. Товари: список

Волна 1, экран 4.

- Устройство: desktop 1440
- Принято: Stitch `5ccffb430d5b4055a2adf50f62f6e063`, [`approved/04-products.png`](approved/04-products.png)

## Зачем этот экран

Каталог как рабочая таблица. Видно, что черновик, что продаётся, что с синхронизацией не так — без колонки на каждый маркетплейс.

## Макет

Текущий пункт `Товари`.

Заголовок: H1 `Товари`, мета `248 товарів`. Primary `Додати товар`, secondary `Імпорт`, secondary `Експорт`.

Быстрые вкладки: `Усі 248` · `Чернетки 18` · `Не на майданчиках 11` · `Не готові 42` · `Закінчуються 12` · `Немає в наявності 9`. Текущая — `Усі`.

Строка фильтров: поиск `Назва, артикул або штрихкод`, селекты `Категорія`, `Бренд`, `Статус`, `Наявність`, `Синхронізація`, ссылка `Скинути`.

Таблица:

| Колонка | Пример |
| --- | --- |
| ☐ | чекбокс |
| Фото | миниатюра 40px |
| Товар | `Конструктор LEGO City «Пожежна частина»`, под ним `TM-10018 · LEGO` |
| Категорія | `Конструктори` |
| Статус | чип `Активний` / `Чернетка` / `Архів` |
| Ціна | `1 890 грн`, под ней зачёркнутая `2 290 грн` |
| Доступно | `13 шт.`, под ним вторичным `резерв 3` |
| Наявність | чип |
| Синхронізація | сводный чип (см. ниже) |

**Нет** колонок `Rozetka` / `Epicentr` / `Prom`. Площадок может быть много; детали по каналам — в карточке товара, вкладка `Майданчики` ([`05-product.md`](05-product.md)).

### Чипы «Синхронізація»

Свод по всем включённым каналам:

| Чип | Когда |
| --- | --- |
| `Активна` | все включённые каналы в порядке (активны / в наличии) |
| `Є питання` | хотя бы один канал: `Не готовий`, `Помилка`, дыры в полях |
| `На модерації` | есть канал на модерации, без ошибок готовности |
| `Часткова` | товар не на всех целевых / часть тумблеров выкл. |
| `Вимкнено` | каналы выключены у активного товара |
| `—` | черновик или ещё никуда не выводили |

Тултип у `Є питання` (TM-10042): `Epicentr: Не заповнено: Матеріал наповнювача, Висота, см` — краткий намёк; полный разбор на вкладке «Майданчики».

Восемь товаров из образца + чернетка `TM-10250`. Цена — базовая.

У TM-10077: `TM-10077 · Не вказано бренд` warning.

У TM-10018-R: вторая строка `дубль кольору TM-10018` вторичным.

Выбраны TM-10155 и TM-10204. Полоса: `Вибрано 2` · `Змінити ціну` · `Змінити кількість` · `Увімкнути на майданчику` · `Вимкнути на майданчику`.

Пагинация `1–50 з 248`.

## Не делать

- Плитку карточек как на витрине.
- Отдельную страницу «товари для синхронізації».
- Логотипы площадок.
- Колонку на каждый маркетплейс.
- Другой сайдбар или другой «вес» таблицы, чем у эталонов костяка.

## Приёмка

- Черновики и «не на майданчиках» находятся за один клик.
- По строке видно доступно и резерв.
- Синхронизация — одна колонка; по `Є питання` понятно, что смотреть в карточке.
- Сайдбар = эталон `241c5204…`, таблица = язык `b8d0d2f…`.
