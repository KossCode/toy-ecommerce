# 16. Акції

Волна 3, экран 16. Реализация — этап 5. Два промпта: список, затем редактор акции.

- Устройство: desktop 1440
- Оболочка, таблица, чипы, поля, расчёт цены — из фундамента
- Данные — [`sample-data.md`](sample-data.md), «Акции»

## Зачем этот экран

Временные скидки поверх цены площадки: на товары, категорию или бренд, на выбранные каналы, на период. Плюс учёт участия в промоакциях Rozetka. CRM сама включает и выключает скидку по датам и следит за ограничениями площадок.

Ограничения, которые экран должен показывать:

- Prom: скидка из фида держится до 45 дней, из API — до 30. Акцию длиннее CRM продлевает сама, но предупреждает.
- Epicentr: старая цена должна быть строго больше новой.
- Rozetka: промоакции площадки — заявка в кабинете Rozetka; CRM хранит факт участия и передаёт `price_promo`.

## Макет A: список

Текущий пункт `Акції`.

Заголовок: H1 `Акції`, мета `3 акції`. Primary `Створити акцію`.

Вкладки: `Усі 3` · `Діють 1` · `Заплановані 1` · `Завершені 0`.

Таблица: `Назва`, `Період`, `Що`, `Знижка`, `Канали` (теги), `Стан` (чип). Три акции из образца. Чипы: `Діє до сьогодні` — success, `Заплановано` — info, `Заявку подано` — нейтральный.

## Макет B: редактор

Крошки `Акції / Осінні знижки на LEGO`.

Слева форма:

- `Назва` `Осінні знижки на LEGO`
- `Період` `10.10.2026` — `20.10.2026`
- `Що входить` — сегментный выбор `Товари` · `Категорія` · `Бренд` (выбрано); селект `LEGO`; подпись `64 товари`
- `Знижка` — сегментный выбор `−%` (выбрано) · `−сума`; поле `10` `%`
- `Округлення` — `До найближчих 10 грн`
- `Канали` — чекбоксы `Rozetka` ✓, `Prom` ✓, `Epicentr`, `Сайт` (disabled, подпись `з’явиться разом із сайтом`)

Справа панель `Попередній перегляд`:

- `Конструктор LEGO City «Пожежна частина» · LP-10018`
- `Rozetka` `2 050 грн` → `1 850 грн`, зачёркнутая `2 480 грн`
- `Prom` `1 890 грн` → `1 700 грн`, зачёркнутая `2 290 грн`
- Ссылка `Усі 64 товари`

Под превью панель предупреждений info: `Prom: знижка з фіду діє до 45 днів. Ця акція — 11 днів.`

Внизу primary `Зберегти акцію`, secondary `Скасувати`.

## Не делать

- Промокоды, бонусы, «2 по цене 1»: это механики витрины, появятся с сайтом.
- Баннеры акции: они в «Контенті».
