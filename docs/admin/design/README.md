# Trio Mio CRM — пакет дизайна для Stitch

Экраны CRM. Что делает каждый раздел — [`../README.md`](../README.md). Поля товара — [`../product-fields.md`](../product-fields.md). Порядок работ — [`../../ROADMAP.md`](../../ROADMAP.md).

Устроен так же, как пакет витрины [`../../design/README.md`](../../design/README.md): один файл — один экран, в конце блок `STITCH PROMPT`. Документы на русском, текст на макетах — на украинском, дословно.

## Чем CRM отличается от витрины

Тот же магазин, другой продукт. Общий только шрифт **Manrope** и аккуратность. Витрина тёплая и продаёт, CRM холоднее и работает:

- светло-серый фон вместо тёплой бумаги;
- плотные таблицы, текст 14px, строки около 40px;
- радиус около 8px вместо 12px;
- никаких иллюстраций, мерчандайзинга, шапки магазина;
- коралловый primary витрины не используется для кнопок; он остаётся только в словесном знаке.

Точные значения задаёт [`00-foundation.md`](00-foundation.md).

## Общие данные

Все экраны берут товары, заказы, цены и ошибки из [`sample-data.md`](sample-data.md). Новые имена, номера и суммы не выдумывать.

## Оболочка

На каждом экране одна и та же оболочка из фундамента. Навигация MVP:

- Огляд
- Замовлення
- Товари
- Категорії
- Бренди
- Наявність
- Ціни
- Інтеграції
- *тонкая линия*
- Клієнти
- Акції
- Аналітика
- Контент
- *внизу колонки*
- Налаштування

Пункта **Характеристики** в навигации нет (фиксированные поля в карточке товара).

Верхняя полоса: поиск `Пошук замовлення або артикула`, имя `Олена`, кнопка `Вийти`.

## Как вызывать Stitch

1. Проект Stitch тот же: `6132458022799915653`, «Trio Mio». Новый проект не создавать.
2. Первым — `00-foundation.md`, `deviceType` `DESKTOP`. Дизайн-систему витрины не передавать.
3. После принятия фундамента — отдельная дизайн-система «Trio Mio CRM».
4. В `prompt` — блок `STITCH PROMPT` целиком.
5. В контекст: файл экрана, `00-foundation.md`, `sample-data.md`.
6. Все экраны CRM — `DESKTOP`, 1440. Мобильной CRM нет.

## Что считается принятым экраном

- Та же оболочка, что на фундаменте.
- Главное действие экрана одно и видно сразу.
- Статусы подписаны словами, не только цветом.
- Красный — только ошибка.
- Данные из `sample-data.md`.
- Нет графиков ради графиков (кроме «Аналітики»).
