# 14. Стани CRM

Волна 2, экран 14. Один лист с панелями состояний, как [`../../design/15-states.md`](../../design/15-states.md) у витрины, но в визуальном языке CRM.

- Устройство: desktop 1440
- Компоненты — из фундамента CRM

Каждая панель: заголовок, одна строка, одно главное действие. Лист подписан сверху `Стани CRM`.

## Панели

1. **Розділ у роботі.** Для разделов волны 3, пока они не реализованы. `Розділ у роботі.` `Клієнти з’являться після підключення всіх майданчиків.` Ссылка `На огляд`. Без иллюстрации и без слова «скоро».
2. **Порожня таблиця за фільтром.** `Замовлень за цей період немає.` Кнопка `Скинути фільтри`.
3. **Порожній розділ.** `Правил цін ще немає.` `Без правила майданчик отримує базову ціну.` Primary `Додати правило`.
4. **Пошук без результатів.** `За запитом «LP-99999» нічого не знайдено.` `Перевірте артикул або номер замовлення.`
5. **Не вдалося завантажити.** `Не вдалося завантажити дані.` `Спробуйте ще раз за хвилину.` Кнопка `Повторити`.
6. **Майданчик не відповідає.** Плашка над таблицей заказов: `Epicentr: замовлення не оновлювались з 09:12.` Кнопка `Повторити`. Стиль warning, не error: заказы других площадок приходят.
7. **Доступ до API не надано.** Плашка в «Інтеграціях» Epicentr: `Оновлення цін і наявності через API недоступне для вашого акаунта. Ціни й наявність ідуть через автооновлення фіду раз на добу.` Ссылка `Як отримати доступ`. Стиль info.
8. **Немає доступу.** `Немає доступу до розділу.` `Зверніться до власника акаунта.` Без кнопки.
9. **Незбережені зміни.** Модалка: `Зберегти зміни в товарі LP-10018?` Кнопки `Зберегти`, `Не зберігати`, quiet `Скасувати`.
10. **Підтвердження дії.** Модалка: `Вимкнути 2 товари на Rozetka?` `Товари зникнуть з продажу на Rozetka після наступної синхронізації.` Кнопки `Вимкнути` и `Скасувати`. Это не destructive-красный: действие обратимо.
11. **Сеанс завершився.** `Сеанс завершився.` `Увійдіть знову, незбережені зміни не втрачено.` Кнопка `Увійти`.
12. **Скелетон таблиці.** Заголовок таблицы и пять серых строк той же высоты. Без спиннера.
13. **Тост успіху.** `Накладну створено. Номер надіслано на Rozetka.`
14. **Тост помилки.** `Не вдалося надіслати статус на Rozetka. Спробуємо ще раз через хвилину.` Действие `Повторити зараз`.
