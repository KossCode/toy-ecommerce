# 07. Категорії

Волна 2, экран 7. Наше дерево + маппинг на листовые категории площадок. Без набора характеристик категории.

- Устройство: desktop 1440
- Оболочка, панели, строка соответствия — из фундамента
- Данные — [`sample-data.md`](sample-data.md)

## Зачем этот экран

Своё дерево (будущее меню сайта Trio Mio) и связь с категориями Prom / Rozetka / Epicentr. От маппинга зависят коды в фиде и обязательные поля площадки.

## Макет

Текущий пункт `Категорії`.

Заголовок: H1 `Категорії`, мета `10 категорій · 248 товарів`. Primary `Додати категорію`. Secondary `Оновити довідники майданчиків`.

Две колонки.

Слева ~360px — дерево: drag handle, название, число товаров. «Конструктори» раскрыта и выбрана. Подпись: `Порядок перетягуванням. Так категорії стоятимуть у меню сайту Trio Mio.`

Справа — карточка:

1. `Основне`: `Назва` `Конструктори`, `Батьківська` `—`, `Товарів` `72`, ссылка `Показати товари`.
2. `Категорії на майданчиках` — три строки соответствия (поиск из кэша справочника, только листья):
   - `Rozetka` → `Дитячі конструктори`, вторичным `ID 97420`
   - `Epicentr` → `Конструктори`, вторичным `code … · attribute set …`
   - `Prom` → `Конструктори`, вторичным `portal_id …`
   Состояния: зіставлено / не зіставлено (warning, `Оберіть категорію`). Подпись: `Лише кінцеві (листові) категорії майданчиків.`

Панели «Набір характеристик» на этом экране **нет**.

## Не делать

- Конструктор характеристик категории.
- SEO и картинки категорий (это «Контент» / сайт).
- Ручной ввод имени категории площадки вместо выбора из справочника.

## Приёмка

- Видно дерево и счётчики.
- Видно маппинг на три площадки.
- Понятно, что сайт = наше дерево.
