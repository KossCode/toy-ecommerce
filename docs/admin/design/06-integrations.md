## Порядок блоків (актуально)

1. **Стан** — потоки CRM.
2. **Помилки** — банер відправки / модерація (якщо є).
3. **Товари на синхронізації** — таблиця SKU на цьому MP (стан каналу, ост. синхр./помилка); Пауза / Прибрати / Відкрити; «Додати» — модалка ACTIVE без enabled.
4. **Підключення** — режим запису людськими підписами (`Вимкнено` / `Лише читання` / `Перевірка без відправки` / `Бойовий режим`; API-значення OFF/READ_ONLY/DRY_RUN/LIVE незмінні) + фід URL + «Копіювати».
5. **Розклад CRM** — таблиця + модалка INTERVAL/CALENDAR (як раніше).
6. **Технічні деталі** — згорнуто.

У «Підключення» підпис явно каже: частоту скачування фіду задає кабінет площадки. Пересбор CRM також іде після змін каталогу (debounce), не лише за розкладом 00:05.

## Не делать

- Сводную страницу со всеми тремя площадками рядом: на «Огляді» это уже есть.
- Настройки, которые живут только в кабинетах площадок, как будто их можно менять отсюда.
- Коды HTTP и JSON на поверхности.

## Приёмка

- Ошибка сформулирована так, что понятно, что сломалось и что делать.
- Видно, сколько товаров не уходит на площадку и почему.
- Ссылку на фид можно скопировать одним кликом.
