# 02. Замовлення: список

Волна 1, экран 2.

- Устройство: desktop 1440
- Оболочка: сайдбар как эталон `241c5204e7404a0aaea58a0425e7ac6e`; таблица — тот же язык, что `b8d0d2f54f58443a93d9a1a426400710`
- Фильтры, чипы, канал, срок — из фундамента
- Данные — [`sample-data.md`](sample-data.md), раздел «Заказы»

## Зачем этот экран

Единая лента заказов со всех площадок. Менеджер работает отсюда: видит новые сверху, подтверждает, создаёт накладные пачкой, находит заказ по номеру CRM или номеру площадки.

## Макет

Текущий пункт `Замовлення`, счётчик `2`.

Заголовок: H1 `Замовлення`, мета `214 замовлень`. Справа primary `Створити замовлення`, secondary `Експорт`. Ручные заказы (Instagram Direct и др.) создаются здесь; канал у таких — `Instagram` или `Ручне`.

Под заголовком быстрые вкладки-счётчики:

`Усі 214` · `Нові 2` · `До відправлення 2` · `Відправлені 9` · `Скасовані 6`

Текущая — `Усі`.

Строка фильтров: поиск `Номер, телефон або номер на площадці`, селекты `Канал`, `Статус`, `Період` (значение `Останні 7 днів`), ссылка `Скинути`.

Таблица, колонки:

| Колонка | Пример |
| --- | --- |
| ☐ | чекбокс |
| Номер | `TM-10481`, под ним вторичным `Rozetka 891204557` |
| Створено | `07.10, 09:15` |
| Клієнт | `Марина Коваль`, под ним `Київ` |
| Склад | `TM-10018 × 1` или `3 товари` |
| Статус | чип, под ним срок подтверждения у «Нове» |
| Доставка | `Нова Пошта` или номер накладной `20450000000001` |
| Сума | `2 050 грн`, вправо |

Строки — все восемь заказов из образца, по убыванию даты. Канал показан тегом в колонке «Номер», отдельной колонки «Канал» нет: так строка короче.

Строка TM-10482 (Epicentr, срок 1 год 20 хв) не заливается цветом: срок warning с иконкой часов, этого достаточно.

Выбраны чекбоксы у TM-10479 и TM-10478. Над таблицей полоса массовых действий: `Вибрано 2` · `Створити накладні` · `Змінити статус` · `Експорт`.

Пагинация: `1–50 з 214`.

## Состояния, которые должны существовать

Не рисовать отдельными экранами, они в `14-states.md`:

- пусто по фильтру: `Замовлень за цей період немає.` и `Скинути фільтри`;
- нет связи с площадкой: плашка над таблицей `Epicentr: замовлення не оновлювались з 09:12.` и `Повторити`.

## Не делать

- Отдельные таблицы по площадкам.
- Логотипы площадок.
- Канбан-доску.
- Красный для «Скасовано».

## Приёмка

- Новые заказы и их срок видны первыми.
- Номер площадки виден рядом с нашим номером: менеджер ищет по любому.
- Массовое создание накладных понятно без подсказки.
