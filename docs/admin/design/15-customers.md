# 15. Клієнти

Волна 3, экран 15. Реализация — этап 5. Два промпта: список, затем карточка клиента.

- Устройство: desktop 1440
- Оболочка, таблица, «ключ — значение», история — из фундамента
- Данные — [`sample-data.md`](sample-data.md): «Клиенты», «Заказы»

## Зачем этот экран

Покупатели из заказов всех каналов в одном месте. Один человек с разных площадок склеивается по телефону. Нужен, чтобы видеть повторные покупки и историю, когда покупатель звонит.

Ограничение: площадки отдают неполные данные. Epicentr показывает покупателя только после подтверждения заказа. Полный профиль (email, согласие на рассылку, адреса) появится с сайтом.

## Макет A: список

Текущий пункт `Клієнти`.

Заголовок: H1 `Клієнти`, мета `386 клієнтів`. Secondary `Експорт`. Primary нет: клиенты появляются из заказов.

Строка фильтров: поиск `Ім’я або телефон`, селекты `Канал`, `Місто`, ссылка `Скинути`.

Таблица — шесть клиентов из образца: `Клієнт` (имя, под ним телефон), `Місто`, `Канали` (теги), `Замовлень`, `Сума доставлених`, `Останнє замовлення`.

Даты последнего заказа: Марина Коваль `07.10`, Ігор Мельник `07.10`, Оксана Бондар `06.10`, Андрій Ткаченко `06.10`, Наталія Савчук `06.10`, Віктор Лисенко `05.10`.

У Марини Коваль два тега `Rozetka` и `Prom`.

## Не делать

- Рассылки, сегменты, бонусы: не входят в первую версию раздела.
- Поля, которых площадки не отдают (email, день рождения).
