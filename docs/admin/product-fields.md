# Поля карточки товара (кросс-таблица)

CRM — единственное место заведения товара. Набор полей = объединение того, что принимают Prom, Rozetka и Epicentr, плюс то, что клиент уже заполняет в экспорте Prom.

Вариантов (колір як різновид) нет: разные цвета = разные артикулы с одинаковым описанием.

**Язык в CRM: украинский + русский.** Вкладки **UA** / **RU** есть и на «Основне», и на «Атрибути». UA — основная. На RU — «Автоматично перекласти з UA» (MyMemory + глосарій коротких значень: `Україна`→`Украина`, `Новий`→`Новый`, `років`→`лет`…). HTML у описах зберігається.

### Що обовʼязково російською (для синку)

| Поле RU | Rozetka | Prom | Epicentr | У CRM |
| --- | --- | --- | --- | --- |
| **Назва (RU)** | **так** (`<name>`) | **так** (базовий `name`) | ні (опц. `lang=ru`) | `*` обовʼязково |
| **Опис (RU)** | **так** (`<description>`) | **так** (`description`) | ні (бажано) | `*` обовʼязково |
| Країна (RU) | ні (param часто одномовний / код) | ні | text-param: пара `lang=ua/ru` якщо текстове | не `*`, але в UI + автопереклад |
| Стан / колір / вік / матеріал / тип / серія (RU) | опц. `value lang=ru` | зазвичай одне значення | text-param: пара мов | не `*`, але вкладка Атрибути UA/RU |
| Бренд, модель, штрихкод, числа | спільно (не «мова») | спільно | коди / числа | без RU-дубля |

Rozetka **не** автоперекладає з UA→RU — тому назва й опис RU критичні. Prom при вимкненій двомовності вимагає заповнені базові `name`/`description` (у нас кладемо RU).

Связанные документы: [`README.md`](README.md), [`../integrations/README.md`](../integrations/README.md), **обязательные поля по площадкам и кросс-таблица** — [`marketplace-required-fields.md`](marketplace-required-fields.md).

## Правило готовности

Товар можно сохранить как `Чернетка` с любыми пустыми полями.

Выгрузка на площадку X разрешена только если:

1. статус CRM = `Активний`;
2. тумблер «Продавати на X» включён;
3. заполнены все поля, обязательные для X (таблица ниже + обязательные атрибуты смапленной категории X, когда справочник загружен).

**Правило обязательности в CRM:** если поле обязательно хотя бы на одном из трёх маркетплейсов — в карточке оно помечено `*` и входит в чек-лист «Готовність до вивантаження».

UI показывает чек-лист и блокирует включение канала или помечает товар «Не готовий».

## Основные поля

| Поле CRM | Тип | Prom | Rozetka | Epicentr | Обов’язковість у CRM | Заметки |
| --- | --- | --- | --- | --- | --- | --- |
| Артикул | string | external id / код | id без дефиса (`TM10018`) | id без дефиса | **да** (всем) | В CRM можно `TM-10018`; на RZ/EC уходит без `-` |

| Опис (UA) | HTML subset | `description_ua` | `description_ua` | `description lang=ua` ≤12160 | **да** | Редактор: пересечение тегов EC (`p br b ul li table…`) |

## Форматы обмена (кратко)

| Майданчик | Контент | Ціна / залишок | Мови в фіді |
| --- | --- | --- | --- |
| **Rozetka** | XML YML по URL (раз в час) | API `PUT /items/mass-update` при типі «Кабінет (API)» | `name`/`description` = **RU**; `name_ua`/`description_ua` = UA |
| **Prom** | Prom YML по URL (контент раз на добу; ціна/наявність раз на 4 год) | API `edit_by_external_id` | Пари `name`/`name_ua`, `description`/`description_ua` (базові без суфікса ≈ RU) |
| **Epicentr** | XML YML з кодами категорій/атрибутів; повний імпорт вручну | Автооновлення ціни/наявності або API `POST /v1/offers` (без кількості — лише статус) | `name`/`description` з `lang="ua"` / `lang="ru"` |

Подробнее: [`../integrations/rozetka.md`](../integrations/rozetka.md), [`prom.md`](../integrations/prom.md), [`epicentr.md`](../integrations/epicentr.md).

## Фиксированные атрибуты (не варіанти)

Общий набор для игрушек. Значения — списки/строки в карточке, не отдельный конструктор характеристик. Под капотом маппятся в `param` каждой площадки (имена/коды из справочника категории).

| Поле CRM | Пример | Prom | Rozetka | Epicentr | Типичная обов’язковість |
| --- | --- | --- | --- | --- | --- |
| Стан | Новий | param | param | param | часто у всех |
| Колір | Червоний | param | param | param | часто; у нас = отдельный артикул, поле всё равно заполняем |
| Вікова група | Від 6 років | param | ≥1 из мин. 3 | isRequired часто | RZ считает в минимум 3; EC по категории |
| Матеріал | Пластик | param | param | param | часто |
| Тип / вид товару | Автомобіль, Головоломка… | param | param | param | по категории |
| Стать дитини | — | param | param | param | по категории |
| Висота / довжина / ширина товару | см или мм | param | param | param | по категории EC |
| Упаковка | Картонна коробка | param | — | — | Prom часто |
| Додаткові (з CSV клієнта) | частота 2.4 GHz, 4WD… | custom param | если есть в категории | если есть в attribute set | не блокируют, если не required |

Rozetka: на товар нужно **не меньше 3** характеристик категории. Epicentr: все `isRequired` из attribute set смапленной категории. Prom: несовпавшие имена становятся «користувацькими» (не в фильтрах).

Точный список кодов игрушечных категорий — после выгрузки справочников (этап 0). До этого UI опирается на эту таблицу и помечает «уточнити після довідника».

## Что не храним в карточке MVP

- Группа разновидностей / `group_id`.
- Бейджи витрины «Хіт», «Новинка».
- Закупочная цена, ячейка склада, поставщик.

## Источник примера полей клиента

Экспорт Prom (CSV, окт. 2026): код товару, назва uk/ru, опис HTML, ціна UAH, фото URL, кількість, група, виробник, країна, вага/габарити упаковки, GTIN, плюс плотный блок характеристик (колір, вік, матеріал, габарити…). Использовать как образец наполнения, не как формат обмена CRM↔площадки.

## Редактор описания

Ограничить панель: абзац, перенос, жирный, список, таблица. Подпись в UI: какие теги принимаются. Автоперевод UA→RU обрабатывает текст между тегами, сами теги не ломает.
