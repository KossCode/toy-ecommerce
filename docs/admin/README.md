## Сейчас

### Огляд

Рабочий стол на день: новые заказы и сколько времени осталось на подтверждение, заказы к отправке, товары с малым остатком, ошибки площадок.

### Замовлення

- Единая лента со всех площадок. Колонка «Канал»: Rozetka, Epicentr, Prom, позже сайт.
- Фильтры: канал, статус, дата, «потрібно підтвердити».
- У нового заказа виден срок подтверждения площадки. Epicentr — 2 часа, Rozetka — 24 часа.
- Карточка заказа: состав, покупатель, доставка, оплата, история статусов, комментарии.
- Действия: підтвердити, скасувати з причиною, змінити статус, створити накладну Нової Пошти. Каждое действие уходит на площадку.

### Товари

- Таблица: артикул, фото, название, бренд, категория, базовая цена, остаток, готовность по каждой площадке.
- Карточка товара:
  - **Основне:** название, описание, фото, бренд, категория, штрихкод, вес и габариты, страна.
  - **Характеристики:** по набору категории, значения из справочника.
  - **Ціни і наявність:** базовая цена, старая цена, количество, ручной флаг «Очікується».
  - **Майданчики:** по каждой площадке — включён ли товар, своё название (если нужно короче), итоговая цена и правило, которое её дало, статус модерации, список того, чего не хватает для выгрузки.
  - **Історія:** изменения цены, остатка и полей: кто и когда.

### Категорії

Своё дерево категорий. У каждой: набор характеристик и соответствие категории каждой площадки.

### Бренди

Список брендов и соответствие бренду в справочниках Epicentr и Prom. Если бренда у площадки нет — отметка «потрібно додати через менеджера».

### Характеристики

Свой справочник характеристик и значений. Для каждой — соответствие характеристике и значениям каждой площадки. Одно наше значение может соответствовать нескольким значениям площадки. Справочники Rozetka и Epicentr загружаются по API, Prom — XML-файлом из кабинета.

### Наявність

Журнал движения остатка: продажа (заказ и канал), отмена, ручная правка, приход. Ручная правка требует причины.

### Ціни

Правила цен по площадкам: по умолчанию, по категории, по бренду, по товару. Тип: точная цена, выше на %, выше на суму. Округление: шаг и направление. Перед сохранением — предпросмотр: сколько товаров изменит цену и у скольких скачок выше порога Rozetka.

### Інтеграції

По каждой площадке: время последней выгрузки фида, последнего опроса заказов и последней отправки цен и остатков; ошибки модерации и импорта; очередь отправок с повтором. Ошибка — понятным текстом и действием «Повторити», без технических подробностей.

### Налаштування

Пользователи и роли, отправитель для накладных Новой Почты, порог «Закінчується» по умолчанию, уведомления о новых заказах в браузере и Telegram. Доступы к площадкам — в «Інтеграціях».

## Потом

Экраны проектируются сейчас, реализация — на этапе 5.

### Клієнти

Покупатели, собранные из заказов всех каналов: имя, телефон, город, заказы, сумма. Склейка одного человека из разных площадок по телефону. Данные с площадок неполные, полный профиль начнётся с сайта.

### Акції

Скидки на период по товарам, категориям, брендам и каналам. Участие в промоакциях Rozetka (`price_promo`). Учитывать ограничения площадок: скидка из фида Prom живёт 45 дней, из API — 30.

### Аналітика

Продажи по каналам, товарам, категориям и брендам; маржа после комиссии площадки; доля отмен; товары, которые часто заканчиваются.

### Контент

Баннеры, страницы и порядок категорий на витрине. Появляется вместе с сайтом.

## Что не входит

- Склад с ячейками, закупки у поставщиков, бухгалтерия.
- Чат с покупателями площадок.
- Настройки, которые есть только в кабинетах площадок: подключение URL фида, тип синхронизации, модерация карточек.
