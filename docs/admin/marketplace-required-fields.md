# Обязательные поля маркетплейсов и кросс-таблица

Сводка для сравнения с карточкой CRM. Источники: исследования в [`../integrations/rozetka.md`](../integrations/rozetka.md), [`epicentr.md`](../integrations/epicentr.md), [`prom.md`](../integrations/prom.md). Карточка CRM и правило «обязательно у нас, если обязательно хотя бы на одном МП» — [`product-fields.md`](product-fields.md).

Обозначения:

- **Обяз.** — без этого товар не создастся / не опубликуется / не будет в наличии по правилам площадки.
- **Усл.** — обязательно в части категорий или при определённых условиях.
- **Желат.** — сильно рекомендуется, но формально не hard-required.
- **Нет** — поле площадка не принимает или не требует.

Языки: UA = украинский, RU = русский.

---

## 1. Rozetka — обязательные поля

Формат: **XML YML** (`offer`). Контент — фид по URL; цена/остаток лучше через API.

| Поле | Тег / место | Обяз. | Примечание |
| --- | --- | --- | --- |
| ID оффера | `offer@id` | **Обяз.** | Только `A–Z a–z 0–9`, **без дефиса** (`TM10018`) |
| Наличие | `offer@available` + `stock_quantity` | **Обяз.** | Без `stock_quantity` товар «немає в наявності»; целое число |
| Цена | `price` | **Обяз.** | UAH |
| Валюта | `currencyId` | **Обяз.** | Обычно `UAH` |
| Категория | `categoryId` (+ желательно `rz_id` у категории) | **Обяз.** | Своя категория в фиде ↔ категория Rozetka |
| Фото | `picture` | **Обяз.** | 1–15 шт., первая — главная |
| Бренд | `vendor` | **Обяз.** | Если нет бренда — `Без бренду` |
| Название **RU** | `name` / `model` | **Обяз.** | ≤ 255; **русское**. С UA на RU Rozetka **не** переводит |
| Описание **RU** | `description` | **Обяз.** | HTML в CDATA, ≤ 50 000 |
| Характеристики | `param` | **Обяз.** | **Минимум 3** на товар; пустые запрещены |
| Название UA | `name_ua` | нет | Если нет — автоперевод с RU |
| Описание UA | `description_ua` | нет | |
| Артикул витрины | `article` | нет | Можно наш `TM-10018` |
| Старая / промо цена | `price_old`, `price_promo` | нет | `price_old` > `price` |
| EAN / штрихкод | `param name="EAN"` | **Усл.** | Обязателен в ряде категорий |
| Вес / габариты упаковки | logistics params | **Желат.** | Без них Rozetka подставит среднее; часть доставок может отвалиться |
| URL товара на сайте | `url` | нет | |

**Итого для Rozetka (минимум):** id, остаток, цена, валюта, категория, ≥1 фото, бренд, **название RU**, **описание RU**, ≥3 характеристики.

## 2. Epicentr — обязательные поля

Формат: **XML YML** без блока `shop`/`categories`; категория и атрибуты — **кодами** Epicentr. Полный контент — ручной импорт; цена/наличие — автообновление или API.

| Поле | Тег / место | Обяз. | Примечание |
| --- | --- | --- | --- |
| Артикул | `offer@id` | **Обяз.** | До 64 символов, **без розділових знаків** (дефис рискован → `TM10018`) |
| Наличие | `available` и/или `availability` | **Обяз.** | Только статус: `in_stock` / `under_the_order` / `out_of_stock`. **Количества нет** |
| Цена | `price` | **Обяз.** | |
| Категория | `category code="…"` | **Обяз.** для нового | Конечная категория (`hasChild=false`) |
| Набор атрибутов | `attribute_set code="…"` | **Обяз.** если есть характеристики | Из PIM категории |
| Фото | `picture` | **Обяз.** | Без фото товар **не создаётся**; несколько URL через запятую в одном теге |
| Название **UA** | `name lang="ua"` | **Обяз.** | ≤ 150; шаблон: категорія + особливість + бренд + модель… |
| Название RU | `name lang="ru"` | нет | Нужен только для русской версии сайта |
| Описание UA / RU | `description lang="ua\|ru"` | **Желат.** | ≤ 12 160; HTML только `p br b ul li table tr td` |
| Бренд | `param paramcode="brand"` | **Обяз.** по набору | Код из справочника Epicentr; новый бренд — через менеджера |
| Обязательные атрибуты категории | `param` с `isRequired` | **Обяз.** | Список зависит от attribute set (возраст, материал…) — из API PIM |
| Старая цена | `price_old` | нет | Должна быть **строго >** `price`, иначе не опубликуют |
| Страна | `param country_of_origin` | часто в наборе | Код значения |
| Штрихкод | `param barcodes` | по набору | |
| Габариты / вес товара | `width`/`height`/`length`/`weight` | по набору | мм и граммы |

**Итого для Epicentr (минимум):** id, статус наличия, цена, category code, attribute_set (если нужны params), ≥1 фото, **название UA**, бренд + все `isRequired` атрибуты категории.

## 3. Prom — обязательные поля

Формат: **Prom YML**. Контент — ночной импорт; цена/наличие — раз в 4 часа (7:00–22:00) или API.

| Поле | Тег / место | Обяз. | Примечание |
| --- | --- | --- | --- |
| ID позиции | `offer@id` | **Обяз.** | По нему обновляется товар при следующих импортах |
| Название | `name` (если не `vendor.model`) | **Обяз.** | Не только цифры; правила по пробелам/дефисам |
| Описание | `description` | **Обяз.** | HTML только в CDATA |
| Категория группы | `categoryId` | **Обяз.** | ID из блока `<categories>` файла |
| Категория маркетплейса | `portal_category_id` | **Обяз.** для нормальной публикации | Листовая категория Prom |
| Цена | `price` | **Обяз.** если есть скидка / для продажи | От 0.01 |
| Фото | `picture` | **Желат. / фактически нужно** | 1–10; без фото карточка бедная, но в YML-таблице «обяз.» сильнее у name/description/id |
| Наличие | `available` | для продажи | `true` / `false` |
| Остаток | `quantity_in_stock` | для учёта остатков | Если включён учёт в кабинете |
| Название UA | `name_ua` | пара с `description_ua` | Работают **только вместе** |
| Описание UA | `description_ua` | пара с `name_ua` | |
| Бренд | `vendor` | нет / усл. | Импортируется, только если бренд уже в базе Prom |
| Артикул | `vendorCode` | нет | До 25 символов |
| Характеристики | `param` | по категории | Имена должны совпадать со справочником категории |
| GTIN / MPN | `gtin` / `mpn` | нет | |
| Страна | `country` | **Желат.** | |
| Габариты / вес упаковки | `dimensions` / `weight` | нет | |

**Итого для Prom (минимум):** `offer@id`, `name`, `description`, `categoryId`, `portal_category_id`, цена (для продажи), фото на практике, `available` + остаток при учёте остатков. Для двуязычности — пары `name`+`name_ua`, `description`+`description_ua`.

## 4. Кросс-таблица: пересечения и уникальное

### 4.1. Поля, общие для всех трёх (пересечение)

| Смысл | Rozetka | Epicentr | Prom | В CRM Trio Mio |
| --- | --- | --- | --- | --- |
| Идентификатор / артикул | `offer@id` (без `-`) | `offer@id` (без розділових) | `offer@id` (+ `vendorCode`) | Артикул `TM-10018` → на RZ/EC без дефиса |
| Цена | `price` | `price` | `price` | Ціна * |
| Старая цена | `price_old` | `price_old` | `oldprice` | Стара ціна |
| Фото | `picture` ×1–15 | `picture` (мин. 1) | `picture` ×1–10 | Фото * |
| Категория площадки | через `rz_id` / binding | `category code` | `portal_category_id` | Категорія CRM + мапінг * |
| Название | RU обяз., UA опц. | UA обяз., RU опц. | `name` обяз. + `name_ua` парой | Назва UA * + Назва RU * |
| Описание | RU обяз., UA опц. | UA/RU желат. | `description` обяз. + `description_ua` парой | Опис UA * + Опис RU * |
| Бренд | `vendor` обяз. | `param brand` обяз. | `vendor` (если в базе) | Бренд * |
| Характеристики | ≥3 `param` | `isRequired` из attribute set | `param` по категории | Фіксовані атрибути (стан, колір, вік…) |
| Наличие для продажи | `stock_quantity` | статус `availability` | `available` + `quantity_in_stock` | Кількість / наявність * |

### 4.2. Где требования расходятся

| Тема | Rozetka | Epicentr | Prom |
| --- | --- | --- | --- |
| **Какой язык названия/описания обяз.** | **RU** | **UA** | Базовый `name`/`description` (у нас = **RU**) + UA парой |
| **Числовой остаток** | **Да**, целое | **Нет**, только статус | **Да**, целое |
| **Мин. число характеристик** | **≥ 3** | Все `isRequired` категории | По правилам категории / кастом |
| **Коды вместо названий** | `paramid`/`valueid` желат. | **Коды category / attribute_set / valuecode** | `portal_category_id`; param по **точному имени** |
| **Формат id** | Только латиница+цифры | Без розділових знаків | Свободнее (`TM-10018` ок) |
| **Лимит названия** | 255 | **150** | API ~110; YML мягче |
| **Лимит описания** | 50 000 | **12 160**, жёсткий whitelist тегов | 50 000 |
| **Фото в теге** | Несколько `<picture>` | Один `<picture>` со списком через `, ` | Несколько `<picture>` |

### 4.3. Уникальное / почти уникальное для площадки

**Только / в основном Rozetka**

| Поле | Зачем |
| --- | --- |
| `stock_quantity` как обязательный контент-фида | Наличие = число |
| Минимум **3** характеристики всегда | Иначе модерация/выдача страдают |
| `name`/`description` именно **RU** как обязательные | Автоперевод только RU→UA |
| `price_promo`, `min_cart_quantity` / `max_cart_quantity` | Промо и лимиты корзины |
| `article` отдельно от `offer@id` | Поиск в кабинете |
| Логистика вес/габариты упаковки | Влияет на отделения/почтоматы |
| EAN в части категорий | Группировка / обязательность по категории |

**Только / в основном Epicentr**

| Поле | Зачем |
| --- | --- |
| `category code` + `attribute_set code` | Без кодов PIM карточка не полноценна |
| Только статус наличия, **без qty** | Синк остатков = смена `in_stock`/`out_of_stock` |
| `name lang="ua"` обяз., RU опц. | Украинский — основной |
| Жёсткий whitelist HTML в описании | Остальное вырезают |
| Бренд только из справочника (код) | Новый бренд — письмо менеджеру |
| `isRequired` атрибуты набора | Список разный по категории |
| Габариты в **мм**, вес в **г** | Не см/кг как у нас в CRM |
| Фото списком в **одном** теге | `, ` между URL |

**Только / в основном Prom**

| Поле | Зачем |
| --- | --- |
| `portal_category_id` / `portal_category_url` | Привязка к дереву Prom |
| `name_ua`+`description_ua` **только парой** | Одно без другого не обновит UA |
| `vendor` только если бренд уже в базе Prom | Иначе не импортируется |
| `selling_type`, `in_stock` («Готово до відправки») | `in_stock` — для ТОП-продавцов |
| `keywords` / `keywords_ua` | SEO на Prom |
| `regions` | Региональность (до 3) |
| `group_id` для різновидів | У нас в MVP нет варіантів |
| Скидка из фида на **45 дней** (из API — 30) | Даты скидки в YML нет |

### 4.4. Что обязательно заполнять у нас в CRM (union)

Если поле обязательно **хотя бы на одной** из трёх площадок — в карточке оно с `*` / в чек-листе готовности:

| Поле CRM | Почему в union |
| --- | --- |
| Артикул | Всем |
| Назва UA | Epicentr (+ Prom UA-пара, Rozetka UA желат.) |
| Назва RU | Rozetka, Prom |
| Опис UA | Prom UA-пара, Epicentr желат. / практика |
| Опис RU | Rozetka, Prom |
| Фото (≥1) | Всем (Epicentr без фото не создаёт) |
| Категорія CRM (+ мапінг) | Всем |
| Бренд | Rozetka, Epicentr |
| Ціна | Всем |
| Кількість / наявність | Rozetka+Prom число; Epicentr → статус |

Не входят в жёсткий union, но часто нужны: модель, штрихкод (усл. RZ), країна UA/RU, вага/габарити, фіксовані атрибути (≥3 для RZ + `isRequired` EC).

## Как пользоваться этим документом

1. Сверить колонку «В CRM» / чек-лист на карточке товара с §4.4.
2. Перед включением тумблера «Продавати на X» — пройти §1 / §2 / §3 для этой площадки.
3. Детали тегов, API и частоты синка — в файлах `docs/integrations/*.md`.

Дата сводки: октябрь 2026 (по состоянию исследований интеграций в репозитории).
