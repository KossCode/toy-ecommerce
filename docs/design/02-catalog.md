# 02. Каталог, desktop

Волна 1, экран 2. После принятой главной.

- Устройство: desktop 1440
- Это шаблон листинга. Им же пользуются поиск, новинки, акции и бренд. На этом экране рисовать только категорию «Конструктори»
- Общие части из фундамента: шапка, подвал, карточка, хлебные крошки, пагинация, чекбоксы, поле цены

## Зачем этот экран

Родитель уточняет подборку и сравнивает товары, не проваливаясь в каждый. Цена, возраст, наличие и бренд доступны без отдельной страницы фильтров.

## Макет

Шапка. Каталог закрыт.

Хлебные крошки: `Головна / Конструктори`

Дальше две колонки.

Левая колонка около 280px, заголовок `Фільтри`. Группы — аккордеоны, первые три открыты. Это пример набора для конструкторов, не вечный список фильтров магазина. Другая категория присылает другие группы. Пол «для кого» на этом экране нет: для конструкторов он не задан. На листинге кукол такая группа появится, отдельным визуальным стилем её не рисовать.

Правая колонка:

- H1 `Конструктори`
- одна строка описания
- `128 товарів`
- строка управления: `Сортування` со значением `Спочатку популярні`, активные чипы выбранных фильтров, ссылка `Скинути`
- сетка карточек: 3 колонки
- пагинация `1 2 3 … 8`

Выбранное состояние фильтров, которое уже применено и видно чипами:

- Вік: `6–8 років`
- Наявність: `В наявності`

Чипы можно снять крестиком.

## Фильтры на макете

`Ціна` — два поля `Від` / `До` и подписи `200` и `5 000`, валюта `грн`.

`Вік` — чекбоксы: `0–12 міс.`, `1–3 роки`, `3–5 років`, `6–8 років` (включён), `9–12 років`, `12+`.

`Бренд` — чекбоксы без выбора: `LEGO`, `Cubika`, `Viga Toys`. Включённых брендов нет, чтобы активных чипов осталось два: возраст и наличие.

`Наявність` — чекбоксы статусов: `В наявності` включён, `Закінчується`, `Очікується`. Пункт «немає» в фильтр не класть: отсутствующее не должно быть способом по умолчанию наполнять выдачу. Если бизнес позже захочет показать отсутствующие, это отдельный чекбокс `Показати відсутні`, выключенный.

`Кількість деталей` — чекбоксы: `До 100`, `100–500`, `500+`.

Кнопки «застосувати» на десктопе нет: список уже в применённом состоянии. На мобильном применение явное, это другой файл.

## Товары в сетке

Шесть карточек, компонент из фундамента. В образце мало конструкторов, поэтому в сетке стоят товары разных категорий с настоящими именами из `sample-catalog.md`. Новые названия не выдумывать. Порядок:

1. LP-10018 — в наличии, скидка, хіт
2. LP-10042 — в наличии, без скидки
3. LP-10077 — закінчується
4. LP-10103 — нет в наличии, кнопка неактивна
5. LP-10120 — очікується
6. LP-10155 — новинка, в наличии

Смешение категорий на демо-сетке допустимо и подписано реальными именами. Не выдумывать седьмой товар.

## Описание под заголовком

`Конструктори для гри вдома: від великих блоків для малюків до наборів, які збирають самостійно.`

## Сортировка

Селект, значение на макете `Спочатку популярні`. В открытом виде не рисовать. Варианты, которые должны существовать у компонента: `Спочатку популярні`, `Новинки`, `Спочатку дешевші`, `Спочатку дорожчі`, `Зі знижкою`.

## Варианты того же шаблона

Отдельные экраны не генерировать. Меняется только заголовок, крошки и предфильтр.

| Маршрут | H1 | Отличие |
| --- | --- | --- |
| Новинки | Новинки | без описания категории, бейдж `Новинка` уже на карточках |
| Акції | Акції | в выдаче только товары со старой ценой, промо-полоса не нужна |
| Бренд LEGO | LEGO | крошки `Головна / Бренди / LEGO` |
| Поиск | отдельный файл | есть запрос и подсказки |

## Не делать

- Фильтры, которые нельзя снять.
- Боковую рекламу.
- Переключатель вида «плитка / список».
- Четыре колонки при открытом сайдбаре на 1440: будет тесно украинским названиям. Три колонки.
- Другую карточку товара.
- Красные ценники на каждой карточке. Скидка только у тех товаров, где она есть в образце.

## Приёмка

- Видно, сколько товаров и какие фильтры включены.
- У отсутствующего товара нельзя нажать «До кошика».
- Цена текущая крупнее старой.
- Шапка, карточка и кнопки те же, что на главной.
