## Зачем пакет устроен по файлам

Stitch генерирует **один экран за вызов**. Если отдать ему все страницы сразу, он изобретёт отдельный визуальный язык на каждой. Поэтому:

1. Сначала утверждается фундамент.
2. Потом пять коммерческих экранов, строго по порядку.
3. Остальные экраны только повторяют уже утверждённые паттерны.

Каждый файл самодостаточен для одной генерации: в нём есть цель, макет, дословный текст, запреты и готовый промпт. Общие правила не копируются целиком — они живут в фундаменте, а промпт требует их соблюдать.

## Как вызывать Stitch

Один вызов `generate_screen_from_text` = один файл = один экран.

1. Проект Stitch один на весь магазин. Не создавать новый проект на каждый экран.
2. Первым генерировать только `00-foundation.md`. `deviceType`: `DESKTOP`.
3. После принятия фундамента создать из него design system Stitch и передавать его id в `designSystem` всех следующих экранов.
4. В `prompt` класть блок `STITCH PROMPT` из файла экрана целиком.
5. В контекст агента класть этот файл, `00-foundation.md` и `sample-catalog.md`. Не класть остальные экраны.
6. Мобильные экраны: `deviceType` `MOBILE`. Десктоп: `DESKTOP`.
7. Если в файле два промпта (поиск, избранное, фильтры), второй запускать отдельным вызовом после принятия первого. Для второго вызова можно править уже созданный экран через `edit_screens`, если это состояние того же экрана, а не новый маршрут.

Текст на макете — только украинский, дословно из файла. Stitch не переводит подписи и не заменяет их на английский.

## Что считается принятым экраном

- Это тот же магазин, что на фундаменте: те же цвета, шрифт, радиусы, шапка, подвал, карточка товара.
- Первый экран отвечает на вопросы родителя: что купить, подойдёт ли, сколько стоит, есть ли в наличии, когда привезут, можно ли доверять, как купить.
- Есть один очевидный следующий шаг.
- Нет нового паттерна, которого нет в фундаменте или в этом файле.
- Нет детского сада в интерфейсе: мультяшных персонажей, игрушечных кнопок, кислого фона, гигантского героя.

## Чего в этом пакете нет специально

Отдельных макетов «Акції», «Новинки» и страницы бренда. Это тот же листинг, другие заголовок и предфильтр. Отдельный макет заставит Stitch придумать вторую витрину.

Отдельного мини-кошика в шапке. Иконка ведёт на страницу кошика. Второй кошик — лишний паттерн.

Оплаты в один клик по номеру телефона. Один путь покупки: кошик → оформление.

Внутренних названий Prom, Rozetka, Epicentr на витрине. Они есть только в CRM.
