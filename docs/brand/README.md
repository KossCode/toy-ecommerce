# Trio Mio — логотип

Название магазина: **Trio Mio**. Подпись в логотипе: «дитячий інтернет-магазин».

## Файлы

| Файл | Что это | Где использовать |
| --- | --- | --- |
| [logo-source.jpg](logo-source.jpg) | Исходник, растр 1024×1024, белый фон | Только как образец. В интерфейс не ставить |
| [logo.svg](logo.svg) | Полный логотип: планеты, звёзды, знак, подпись. Вектор, прозрачный фон | Соцсети, упаковка, страница «Про магазин», экран входа CRM |
| [logo-wordmark.svg](logo-wordmark.svg) | Только знак «TRIO♥MIO». Вектор, прозрачный фон | Шапка сайта, подвал, навигация CRM, фавикон-основа |

Оба SVG получены автоматической трассировкой исходника. Что это значит:

- форма и цвета сохранены, мелкая фактура на планетах (полосы, кратеры) упрощена до заливки;
- по краям букв есть тонкий светлый ореол от сглаживания исходника. На светлом фоне его не видно, на тёмном — заметен. Для тёмного фона нужна чистая версия;
- файлы тяжёлые (около 350–600 КБ). Для сайта их нужно оптимизировать (SVGO) или заменить чистой векторной отрисовкой.

**Чистый вектор.** Если логотип делал дизайнер, лучше попросить у него исходник (AI, Figma, SVG). Если исходника нет — знак «TRIO♥MIO» стоит перерисовать вручную по этой трассировке: это несколько скруглённых букв и сердце, работа на пару часов. Полный логотип с планетами можно оставить трассированным.

## Цвета логотипа

Сняты с исходника.

| Где в знаке | Цвет |
| --- | --- |
| T, последняя O | `#FEC157` жёлтый |
| R | `#81BFBC` бирюзовый |
| первая i, M | `#B496CA` лавандовый |
| первая O | `#7EB6D7` голубой |
| последняя i | `#90C6AE` мятный |
| сердце | `#FD8086` коралловый |

Все цвета светлые: на белом фоне у них низкий контраст. Для текста, кнопок и иконок интерфейса они не годятся, только для декоративных акцентов и иллюстраций.

## Правила

- Логотип не перерисовывается в макетах Stitch. В промптах знак описывается словами, в реализации ставится SVG.
- Минимальная высота знака «TRIO♥MIO» — 20px на экране.
- Вокруг знака свободное поле не меньше высоты буквы O.
- Не менять цвета букв, не обводить, не класть на пёстрый фон.
- Планеты-персонажи — только в полном логотипе. В интерфейсе витрины и CRM их не повторять.

## Открытые вопросы

1. **Палитра витрины.** Принятый фундамент витрины построен на коралле `#D95D39` и тёплом фоне. Логотип пастельный и многоцветный. Варианты: оставить витрину спокойной и опереть акценты на один цвет логотипа; или пересобрать фундамент витрины под пастель. Решить, когда витрина вернётся в работу.
2. **Характер витрины.** В фундаменте витрины записано «без мультяшности». Логотип мультяшный. Совместимо, если персонажи остаются в логотипе, — но это нужно подтвердить.
3. **Исходник логотипа.** Есть ли он у автора логотипа.
4. **Домен.** В документах стоит плейсхолдер `triomio.ua`.
